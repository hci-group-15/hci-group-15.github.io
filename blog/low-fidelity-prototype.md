## Lo-Fi Prototype B
We initially started using Figma, but quickly ran into some limitations with the design we wanted to go with, prompting us to switch to writing everything in Vue.js.

While that can take quite a bit more time, we felt like it would help us in the long run, next to the fact that one of the group members had used Vue.js quite a lot already.
That is, we can reuse some of the code from the lo-fi prototype in the high fidelity prototype, which is not (really) possible with Figma.

It also required some more proper coordination between the members to avoid merge conflicts for as long as possible,
which proved to be a bit of a learning curve for the two members of the group that had not really used `git` extensively up until this point.

In the end, we did likely spend a bit more time than others may have to achieve a similar result, but building on top of this, had we elected to implement more features,
but it also gave an introduction to Web Development to this part of the team, and giving us the flexibility to implement things that are not possible to do effectively in Figma.

For a next time, we should have committed to going with WebDev sooner to waste less effort.
